## Documentation principles

1. Every public API has a documented contract.
2. Business intent and technical implementation are kept distinct.
3. Unverified observations are marked **Needs Review**.
4. Never publish credentials, secrets, customer data, or confidential algorithms.
5. Changes to public interfaces require corresponding documentation updates.

## Publishing

Documentation source is Markdown. Review customer-facing content before publishing or exporting it.
