# Getting Started — Developer Onboarding

## Learning outcomes

A new developer should understand the architecture, configure an approved development environment, trace one core business workflow, and run a safe read-only example.

## Suggested onboarding path

1. Read the [architecture overview](../architecture/index.md).
2. Review the [credit module](../modules/credit/index.md).
3. Understand the [API reference template](../api-reference/PACKAGE_TEMPLATE.md).
4. Walk through one approved end-to-end workflow with a mentor.

> **Needs Review:** Specify approved environments, tooling, access procedure, and training tasks.
